Fashion AI v3 — тест распознавания одежды

Модель: FashionSigLIP (новая) · FashionCLIP (старая)

Модель работает прямо в твоём браузере: фото никуда не отправляются, API не нужен, это бесплатно. Загрузи свои вещи. Если тип неверный — выбери правильный: модель запомнит пример и будет узнавать похожие вещи.

Загружаю модель (~150–200 МБ, только в первый раз)…
Модели: Marqo-FashionSigLIP и Marqo-FashionCLIP (Apache-2.0) через Transformers.js. Это zero-shot: модель выбирает самую похожую метку из списка ниже по смыслу, без дообучения. Проценты — относительная уверенность внутри каждой группы. Натуральную кожу от экокожи по фото надёжно не отличить, поэтому это одна метка.
Твоих исправлений сохранено: 0 (хранятся только в этом браузере).
